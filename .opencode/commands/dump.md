Topic: $ARGUMENTS

Run `python3 tools/new.py dump $ARGUMENTS` with the bash tool. Then tell the user, in two sentences, the path of the new file and that they should write everything they know there, from memory, without looking anything up. Do not write any content into it, do not suggest content, and do not ask questions about the topic yet.
